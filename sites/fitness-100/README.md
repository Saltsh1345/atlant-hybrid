# Фитнес 100 — лендинг фитнес-клуба

Статический одностраничный сайт: `index.html` + `styles.css` + `script.js`.
Сборки нет — файлы отдаются как есть, поэтому сайт открывается локально двойным
кликом и деплоится на любой статический хостинг без настроек.

## Локальный запуск

```bash
cd sites/fitness-100
python3 -m http.server 4173   # http://localhost:4173
```

## Что заменить на реальные данные

Все контакты и цены — демонстрационные заглушки:

| Что | Где |
| --- | --- |
| Телефон `+7 (700) 000-00-00` | `index.html` (шапка, контакты, подвал, CTA), `script.js` → `CLUB.phone` |
| Номер WhatsApp | `script.js` → `CLUB.whatsapp` (только цифры) |
| Почта `hello@fitness100.kz` | `index.html` |
| Адрес `ул. Примерная, 100` | `index.html` (блок «Адрес», карта, подвал) |
| Ссылки на Instagram / Telegram / 2ГИС | `index.html` |
| Расписание групповых | `script.js` → `CLUB.schedule` |
| Тарифы и цены (₸) | `script.js` → `CLUB.plans` |
| Вопросы и ответы | `script.js` → `CLUB.faq` |
| Тренеры и отзывы | `index.html` |

## Форма заявки

Бэкенда нет: после валидации данные собираются в текст и открываются в WhatsApp
по ссылке `wa.me`. Никуда больше данные не уходят. Чтобы принимать заявки в CRM
или на почту, замените обработчик `form.addEventListener('submit', …)` в
`script.js` на `fetch` к своему эндпоинту.

## Деплой

Проект развёрнут на Vercel как отдельный статический проект (без Git-интеграции,
загрузкой файлов). Для повторного деплоя достаточно снова отправить эти три файла
в тот же проект.
