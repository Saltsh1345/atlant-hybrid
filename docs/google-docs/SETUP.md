# Настройка автоматических паспортов в Google Docs

Cursor не подключён к вашему Google Drive, поэтому один раз требуется ручная настройка владельцем аккаунта. После неё локальная команда будет создавать или обновлять Google Doc в отдельной папке.

## 1. Создать отдельную папку

1. Откройте [Google Drive](https://drive.google.com/).
2. Создайте папку `Atlant-Hybrid — Паспорта этапов`.
3. Откройте папку.
4. Скопируйте ID из адреса:
   `https://drive.google.com/drive/folders/ЭТОТ_ID`.

## 2. Создать Google Apps Script

1. Откройте [script.google.com](https://script.google.com/).
2. Нажмите «Новый проект».
3. Назовите проект `Atlant-Hybrid Passport Sync`.
4. Замените содержимое `Code.gs` кодом из [Code.gs](Code.gs).
5. Откройте «Настройки проекта» → «Свойства скрипта».
6. Добавьте:
   - `ATLANT_PASSPORT_FOLDER_ID` — ID папки из шага 1.
   - `ATLANT_PASSPORT_SECRET` — длинная случайная строка не короче 32 символов.

Секрет нельзя отправлять в чат или сохранять в Git.

## 3. Развернуть Web App

1. Нажмите «Начать развёртывание» → «Новое развёртывание».
2. Тип: «Веб-приложение».
3. Выполнять от имени: `Я`.
4. Доступ: `Все` или `Anyone`.
5. Подтвердите доступ к Google Docs и Google Drive.
6. Скопируйте URL веб-приложения, который заканчивается на `/exec`.

Доступ `Anyone` необходим для вызова webhook без интерактивного Google OAuth. Запросы дополнительно защищены секретом. Если такой режим запрещён политикой вашего Google Workspace, автоматическая синхронизация потребует отдельного Google Cloud OAuth/service-account решения.

## 4. Добавить локальные значения

Откройте локальный файл `.env.local` в корне проекта и добавьте:

```dotenv
GOOGLE_DOCS_PASSPORT_WEBHOOK_URL=https://script.google.com/macros/s/.../exec
GOOGLE_DOCS_PASSPORT_SECRET=тот_же_секрет_из_свойств_скрипта
```

`.env.local` уже исключён из Git.

## 5. Проверить синхронизацию

В терминале из корня проекта выполните:

```powershell
npm run passport:sync -- docs/passports/stage-00-governance.md
```

Команда должна вывести ссылку на созданный Google Doc. Ссылку нужно записать в паспорт этапа.

## После каждого принятого этапа

1. Обновить локальный паспорт.
2. Запустить `npm run passport:sync -- <путь-к-паспорту>`.
3. Записать URL Google Doc в паспорт и `docs/PROGRESS.md`.
4. Заморозить файлы этапа.
5. Создать commit только после прямой команды пользователя.
