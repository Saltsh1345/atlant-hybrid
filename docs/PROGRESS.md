# Atlant-Hybrid — журнал прогресса

## Правила статусов

- `НЕ НАЧАТ` — изменения этапа запрещены без команды начать.
- `В РАБОТЕ` — разрешены только файлы и задачи текущего этапа.
- `ОЖИДАЕТ ПРИЁМКИ` — разработка остановлена; требуется проверка пользователя.
- `ЗАВЕРШЁН — ЗАМОРОЖЕН` — этап принят; изменения запрещены без отдельного разрешения.
- `ЗАБЛОКИРОВАН` — требуется ручное действие пользователя.
