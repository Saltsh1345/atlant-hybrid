# Паспорта этапов Atlant-Hybrid

Каждый этап имеет отдельный Markdown-паспорт. Паспорт создаётся до начала этапа и дополняется по мере работы.

## Обязательные поля

- Цель и границы этапа.
- Явно разрешённые изменения.
- Явно запрещённые изменения.
- Исходное состояние.
- Выполненные изменения.
- Изменённые и созданные файлы.
- Проверки и результаты.
- Известные ограничения.
- Ручные действия владельца проекта.
- Решения пользователя.
- Статус приёмки.
- Git commit после явной команды пользователя.
- Ссылка на синхронизированный Google Doc.

## Правило фиксации

1. Агент завершает только текущий этап.
2. Агент обновляет паспорт и ставит статус `ОЖИДАЕТ ПРИЁМКИ`.
3. Пользователь проверяет результат.
4. Только по команде пользователя этап получает статус `ЗАВЕРШЁН — ЗАМОРОЖЕН`.
5. Паспорт синхронизируется с Google Docs.
6. Следующий этап начинается только по новой команде.
